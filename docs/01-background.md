# 01 · 背景与目标

## 1. 现状

| 项 | 事实 |
|---|---|
| Agent | 官方 pi `1.5.0`（2026-11-02 升级完成，`pi -p` 哨兵实测通过） |
| 平台 | Windows 11，Node `v24.14.0`，npm `11.9.0` |
| 配置 | `~/.pi/agent`（settings、models、auth、extensions、skills、prompt templates、sessions） |
| 扩展 | 你自己装在 `~/.pi/agent/extensions` 的那批（本项目不自带、也不新装：扩展/技能/提示词模板由你的配置决定） |
| 会话 | `~/.pi/agent/sessions/<编码 cwd>/<ISO 时间戳>_<uuid>.jsonl`，按 cwd 分组、随使用增长（A-01 以"等于目录数"判定，不写死数字） |
| 项目 | 多个并行项目目录（新会话先选目录，见 A-07） |
| 用法特征 | 长会话、多项目、大量自有 slash 命令、依赖 cron 定时任务、常看 diff 与工具输出 |

## 2. 问题（用户原话归纳）

1. **长对话难读**：终端里滚动、折叠不便，工具调用与 Markdown 混在一起。
2. **多会话难管**：切换靠命令，历史靠翻文件，无法一眼看到"哪些在跑、哪些昨天停在哪"。
3. **diff / 文件难看**：改了什么要另开窗口看。
4. **可视化能力被浪费**：模型给的表格、图、长文档在 TUI 里只能看文本。
5. **但不想换引擎**：第三方 GUI（PI-Desktop、PI WEB daemon 版）会**自带运行时/自有数据目录**，等于把你的 pi 复制一份，配置、扩展、会话都要重新对齐。**明确不要这个。**

## 3. 目标

> 给现有 pi 加一层**可丢弃的**浏览器外壳：同一份配置、同一批扩展、同一份会话文件、同一个官方二进制。

**必须成立的三条（缺一即失败）**

- G-1 底层是用户主目录 `~/.pi/agent` 下**已安装的官方 pi 1.5.0**，不新装引擎
- G-2 现有扩展的注入与命令在壳里**原样生效**（验收见 A-02 / A-05）
- G-3 卸载 = 删掉 `~/pi-shell` 整个目录 + 删除桌面快捷方式（一个 `.lnk`，可选功能）；pi 侧无项目残留（pi 自身运行期会更新 `settings.json` / `models-store.json` / `state/`，不属本项目写入）

## 4. 非目标（本版本明确不做）

| 不做 | 原因 |
|---|---|
| 多用户 / 账号体系 | 单人本机使用 |
| 公网访问 / 远程手机 | 安全模型撑不住；确有需要再单独立项（M3） |
| 工具调用审批层（Allow/Ask/Deny） | pi 本身无此机制（`docs/security.md` 明示不逐条审批），伪造一层会给人错误的安全感 |
| 与 TUI 同时操作同一会话 | pi 无锁，**无法自动检测**（D-08）；只能打开前提示 + 备份，不承诺技术阻止 |
| 编辑器 / IDE 功能 | 目标只是"看和用"，不是改代码的 IDE |
| 插件市场 / 扩展安装 UI | 用 `pi install` 即可 |
| 重写 pi 的 TUI | 终端体验保持不变，二者并存 |

## 5. 约束

| 编号 | 约束 |
|---|---|
| C-01 | 只绑 `127.0.0.1`，不监听 `0.0.0.0` |
| C-02 | 不修改 `~/.pi/agent` 下除会话 JSONL 之外的任何文件。**唯一例外**：A-06 测试期可临时写入 `~/.pi/agent/extensions/`，测试后立即删除并在 `logs/` 留痕（仅限测试，产品代码路径不得使用） |
| C-03 | 不引入运行时第三方依赖（bridge 只用 Node 内置模块） |
| C-04 | 前端不加载任何远程资源（无 CDN、无外链字体） |
| C-05 | 遵循 pi 的协议约定：JSONL 只按换行符分行；stdout 只放协议数据；日志写日志文件，**仅 TTY 时镜像到 stderr**（非 TTY 不写 stderr，避免 Windows 管道同步写阻塞，见 H-15） |
| C-06 | 文档先行：本阶段不写代码，评审通过后才进 M0 |

## 6. 成功标准（整体）

- 连续使用 5 天，每天至少一次"不开终端完成一轮任务"
- 会话文件与会话内容与 TUI 完全一致，无损坏、无丢失 —— **前提：不在终端与网页同时操作同一会话**（D-07 / Q-2）。发生外部写入的人工判据：网页未发消息的时段，该会话文件的 mtime 或条目数发生变化
- 卸载后 `~/.pi/agent` 中不出现由本项目写入的文件（以代码审查为准，不以快照哈希为准）
