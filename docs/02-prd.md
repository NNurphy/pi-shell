# 02 · 需求文档（PRD）

版本 **v1.0.0**（随首个公开发布定稿）｜ 状态：已定稿

---

## 1. 用户与场景

**目标用户**：单机 Windows 11 的 pi 用户。会用命令行，但不想为了"看得舒服"而换引擎。

| 编号 | 场景 | 现状痛点 | 期望 |
|---|---|---|---|
| S-1 | 回顾昨天某轮会话 | 要翻目录、用命令 resume | 网页按项目列出会话，点开就看 |
| S-2 | 继续某会话追问 | TUI 内切换麻烦 | 点开后直接输入 |
| S-3 | 看 AI 改了什么 | 终端 diff 难读 | 工具调用折叠；M2 加只读 diff |
| S-4 | 调自定义命令 | 记不住名字 | Ctrl+K 聚合扩展命令/技能/模板 |
| S-5 | 扩展弹窗询问 | **预留能力**：本机 4 个扩展均未使用四种对话框（仅 `notify` / `setStatus`） | 网页弹模态，点完回传 |
| S-6 | 多会话并看 | TUI 一次一个 | 会话树 + "本壳正在使用"标记 |

## 2. 功能需求

### 2.1 M0 · 协议打通

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F-00a | 启动桥并拉起 `pi --mode rpc` | P0 | `/api/health` 返回 `pi.version="1.5.0"` 且 `state="idle"` |
| F-00b | 发消息并流式显示 | P0 | 首字 ≤3s；单条回复 ≥2 次增量更新（非一次性整段） |
| F-00c | 中止 | P0 | 点击 ≤2s 页面停止追加；`get_state.isStreaming` ≤5s 转 `false` |

### 2.2 M1 · 可用壳

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F-01 | 会话列表：按工作目录分组；字段 = 标题（首条用户消息前 30 字）、最后更新时间、末条**消息**摘要（≤120 字符）、`attached` 标记 | P0 | A-01。**标题来源与字段定义见 03 §7**（会话无 name 字段） |
| F-02 | 会话渲染：Markdown（标题/列表/代码块/表格/链接）、thinking 折叠、工具调用折叠、图片 | P0 | 按 **03 §14.1** 的 12 项清单，用样本 A（工具密集）+ 样本 B（含图片）逐项通过 |
| F-03 | 发送：纯文本、图片（`images`）、**文件引用（前端读取 ≤200KB 注入）** | P0 | 三种各一次，回复能复述文件中特定字符串 |
| F-04 | 运行中控制：中止、steer、followUp、清空队列 | P0 | Esc = `clear_queue` 后 `abort`；行为与协议语义一致（不承诺与 TUI 像素级一致） |
| F-05 | 模型与思考级别：列出、切换 | P0 | A-03（直通一致 + TUI 抽查 3 项） |
| F-06 | 命令面板：扩展命令、技能（`/skill:name`）、提示词模板 | P0 | A-05；面板项与 `get_commands` 完全一致 |
| F-07 | 扩展对话框桥：`select`/`confirm`/`input`/`editor` | P1 | A-06 |
| F-08 | 扩展通知桥：`notify`→toast；`setStatus`→状态条；`setWidget`→**编辑区上方字符串块** | P1 | 回归 #8（**在门禁内**，见 04 §4/§5） |
| F-09 | 工作区切换：选目录后新建会话落在该目录 | P0 | A-07；切换后对话区清空、旧会话仍在列表（语义见 03 §3）；代价 ≈3s（含 MCP 重启） |
| F-16 | 断线重连与手动重试 | P1 | A-08；恢复时按 `entry.id` 游标补齐 |

> **F-07/F-08 止损**：M1 内未通过 A-06 → 顺延 M2，M1 按 **17.5h** 结算；**M2 预算相应变为 26h**（23 + 3），总量不变（见 04 §2）。

### 2.3 M2 · 日常主力

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F-10 | 分支：`fork`（entryId 必填）/ `clone` / `get_tree` | P1 | fork 后出现新 `.jsonl` 且 `get_state.sessionFile` 变化；clone 后原文件条目增加、树出现新分支 |

## 3. 非功能需求

| ID | 要求 | 验证方式 |
|---|---|---|
| N-01 | 仅监听 `127.0.0.1` | `netstat -ano \| findstr 7788` |
| N-02 | 1000 条会话首屏可交互 < 3s | `PI_SHELL_SESSIONS_DIR` + `--session-dir` 同时指向合成目录 |
| N-03 | bridge < 250MB、浏览器标签 < 800MB、2h 无单调增长 | M1 收尾 T-14，每 30 分钟记录 |
| N-04 | 桥代码中**不存在**对 `~/.pi/agent` 的写调用；运行期变更仅限 pi 自身写入的白名单：`settings.json`、`models-store.json`、`state/`、`sessions/`、`trust.json`、`logs/` | 代码审查 + 目录快照对照该白名单 |
| N-05 | 前端零远程资源 | 断网可用；Network 无外部域名 |
| N-06 | **pi 子进程**崩溃自动重启（5 分钟 ≤3 次） | 手动 kill 子进程 |
| N-09 | **桥进程**崩溃 → 页面横幅 + 重启指引（不自动拉起） | 手动 kill node |
| N-07 | 日志不含正文与密钥 | 正则扫描 + 抽查 |
| N-08 | 中文路径、含空格路径正常 | 两 cwd 各一次（含 `PI_SHELL_EXTRA_ARGS` 带空格路径的用例） |

## 4. 数据与状态

| 数据 | 来源 | 持久化 | 备注 |
|---|---|---|---|
| 会话索引 | 扫 `PI_SHELL_SESSIONS_DIR`：header + 首条 user + 末条 message | 否（内存） | 单文件最多读前 64 条/64KB + 末尾 |
| 会话内容 | `get_entries`（含 entry id，可 `since` 补齐） | 否 | 会话由 pi 持久化 |
| 偏好 | `localStorage` | 是 | 不含密钥 |
| 日志 | `logs/bridge.log` | 是 | 5MB 轮转、脱敏 |

不保存 API key、不写 cookie、不把正文写日志。

## 5. 明确不做

1. 账号 / 登录 / 多用户
2. 公网 / 远程 / 手机（M3）
3. 工具调用审批层
4. 编辑器 / IDE
5. **用技术手段阻止"双端同开"**（pi 无锁，做不到；只提示 + 备份，见 D-08）
6. 第三方运行时依赖、远程资源
7. daemon 常驻、开机自启
8. 全文检索
9. 探测 TUI 占用（同上第 5 条）

## 6. 验收探针

| ID | 检查 | 判定（唯一口径） |
|---|---|---|
| A-01 | 会话列表 | 分组数 == **含有 `.jsonl` 的目录数**；至少一个分组；每项 title/updatedAt/lastSnippet/status 非空（title 按 03 §7 规则） |
| A-02 | 扩展生效 | `get_commands` 含你本机扩展注册的至少一条命令；以 `--no-extensions` 启动时该命令消失。**判定只依赖 bridge 侧命令集，不依赖 F-08 的页面渲染** |
| A-03 | 模型 | `/api/models` == `get_available_models`（集合相等）；**另**人工抽查 3 个模型与 TUI `/model` 列表一致 |
| A-04 | 落盘一致 | 发送后 5s 内出现新 `.jsonl`；页面最后一条 assistant 对应的 **entry id** 能在该文件中找到（消息对象本身无 id，见 03 H-6） |
| A-05 | 命令面板 | `get_commands` 非空（含你本机配置的扩展命令/技能/提示词模板） |
| A-06 | 扩展弹窗桥 | `-e <绝对路径>` 加载 `test-ext/select-demo.ts` → 触发 `select` → 回执后 pi 收到所选值 |
| A-07 | 工作区切换 | 切到任一已存在目录 → 新建会话 → **发送一条消息** → 文件落在对应 `--<编码 cwd>--` 分组（空会话不落盘，见 03 H-5） |
| A-08 | 断线恢复 | kill bridge 再启动 → 页面 ≤15s 恢复，或 ≤15s 出现"重试"按钮且点击后恢复；补齐后无重复条目 |

A-01~A-05、A-07 在 M1 收尾必须全绿；A-06 可按止损延后；A-08 允许"手动重试"分支通过。
