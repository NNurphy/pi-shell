## 1. 整体骨架

```
┌───────────────────────────────────────────────────────────────────────────┐
│ Header 44                                                       Changes 4 │
├──────────────┬──────────────────────────────┬───────────────────────────┤
│              │ Column 01                    │ Column 02                 │
│  Sidebar     │ ┌ header 36 ───────────────┐ │ ┌ header 36 ────────────┐ │
│  320         │ │ 01 B8 视觉重设计  v4.1 ▾ │ │ │ 02 会话树 949  ⤢ ×    │ │
│  (可折叠 56) │ ├──────────────────────────┤ │ ├───────────────────────┤ │
│              │ │ 会话流（唯一滚动容器）   │ │ │ 会话流（独立滚动）    │ │
│  分组行 32   │ │                          │ │ │                       │ │
│  会话行 68   │ │                          │ │ │                       │ │
│              │ ├──────────────────────────┤ │ ├───────────────────────┤ │
│              │ │ Composer 卡片            │ │ │ Composer 卡片         │ │
│              │ └──────────────────────────┘ │ └───────────────────────┘ │
└──────────────┴──────────────────────────────┴───────────────────────────┘
                                                          [Panel 340 浮层/停靠]
```

- **外壳不滚动**：`html, body { height:100dvh; overflow:hidden }`。滚动只发生在三个地方：侧栏列表、每个会话列、右侧面板。这是"面板风格不统一"的根因之一——现状 `.log` 与页面滚动混在一起。
- 列之间、侧栏与列之间只用 **1px `--line`**；面板用 1px `--line-strong`。

**Grid 定义**

```css
.shell {
  display: grid;
  grid-template-columns: var(--sidebar-w) minmax(0, 1fr) var(--panel-w, 0);
  height: calc(100dvh - var(--h-header));
  transition: grid-template-columns var(--dur-3) var(--ease-std);
}
.main-area { display: grid; grid-template-columns: repeat(var(--col-count), minmax(0,1fr)); min-width: 0; }
```

| 变量 | 值 | 说明 |
|---|---|---|
| `--h-header` | 44（≤768：48） | |
| `--sidebar-w` | 320（紧凑 264） | 可拖拽 260–520，双击恢复 320；存 `localStorage['pi-shell.sidebarWidth']` |
| `--sidebar-rail` | 56 | 折叠态（只显示计数与图标位） |
| `--panel-w` | 340（树）/ 420（文件、Diff） | `<1280px` 时面板改浮层，不占列宽 |
| `--col-count` | 1 / 2 / 3 | 用户手动切换，持久化到 localStorage |
| `--col-min` | 1 列：0 ｜ 2 列：400 ｜ 3 列：340 | 低于最小宽度就降级列数（见 §3） |
| `--measure` | 860px | 单列时正文/Composer 最大宽度（`min(100%, 860px)` 居中）；多列 = 按列铺满 |

**阅读宽度**
- 单列：内容与 Composer 统一 `max-width: min(100%, 860px)`，水平居中（左右留白随宽度增长，最小 32px）。
- **同类同宽**：assistant 正文、thinking、工具块、代码块、用户气泡一律等于容器宽度（Q6 删掉了 assistant 段落 68ch 的单独限宽——那会让正文比工具块窄一截，读起来像两条不同宽的栏）。
- 多列：正文 `max-width: 100%`，列内左右 padding 16px。列宽 < 520 时正文自动降至 14/22（保证 34+ 汉字/行）。

## 2. 侧栏

### 2.1 结构（从上到下）

1. 侧栏头 36px：`会话` 标题 + **过滤输入**（占满剩余宽度，高度 28，仅在聚焦时显示边框，默认只有下划线）+ `＋ 新会话`（28×28 quiet）。
2. **AGENT 会话板块**（置顶，独立）：组标签 + 计数，组内会话行带 `AGENT` 徽标。
3. 普通分组：按 cwd 分组，按最近更新时间倒序；组可折叠（状态持久化）。
4. 底部 32px 状态条：桥状态点 + 等宽 `pid 76540 · pi 1.5.0`（等宽 11px，`--ink-3`）。

### 2.2 折叠阈值（三态）

| 视口 | 侧栏形态 | 触发 |
|---|---|---|
| ≥1024 | 固定展开 320 | 手动可折叠到 rail 56（记忆） |
| 769–1023 | 默认 rail 56，hover 展开为 320 **浮层**（不挤压列宽） | 点击固定/取消 |
| ≤768 | **隐藏**，由 Header 的 `☰` 打开抽屉 300（≤84vw） | 遮罩点击 / Esc / 选中会话后关闭 |

rail 态（56px）只显示：`＋`、AGENT 计数点、每个 cwd 的首字母徽标（2 字符，等宽）+ 该组 streaming 点。**不做**图标墙。

### 2.3 行规格

| 行 | 高 | 左 padding | 内容 |
|---|---|---|---|
| 组行 | 32 | 12 | caret 12 + 路径（等宽 12，中间省略）+ 计数（等宽 11，右） |
| 会话行 | 52（紧凑 40） | 12（含 2px 选中条位） | 标题 13/18 单行 + 副行 11/16 等宽 |
| AGENT 徽标 | — | — | 10px 等宽，`--accent-soft` 底，`--r-xs` |

侧栏底 `--surface`，选中行底 `--canvas`（“灰轨道上的纸洞”）+ 左 2px `--accent`；分组行、会话行均为 0 圆角。
> 目标视觉：`preview-desktop-single.png` 左侧。

行内操作（删除/克隆）只在 hover 或选中行出现；≤768px 常显（44×44 命中区）。

## 3. 多列容器（1–3 列）

### 3.1 列是什么

**一列 = 一个引擎实例 + 一个会话**，拥有独立的：会话流滚动位置、Composer 草稿、模型选择、思考级别、streaming 状态、Changes 计数。

列不是 tab（不同列同时在线、同时 streaming），也不是分屏预览（每列都可交互）。

### 3.2 列头（36px，仅多列时显示）

```
┌────────────────────────────────────────────────────────────┐
│ 01  B8 视觉重设计 · 设计系统      v4.1 ▾   ⤢  ⋯        ●  │
└────────────────────────────────────────────────────────────┘
```

- 序号 `01/02/03`：等宽 11px `--ink-3`（列的稳定身份，不随标题变）。
- 标题：13px 600 单行省略，点击=聚焦该列。
- 模型 chip：`v4.1 ▾` 等宽 11px，点击直接切模型（该列独立）。
- 操作：`⤢` 聚焦（其他列收成 40px 窄条或关闭，用户可选）、`⋯`（克隆会话、打开 Changes、关闭列）。
- 右端状态点：streaming `--accent`、错误 `--danger`、idle 无点。
- **活动列**标记：列头下边 2px `--accent`（非活动列 1px `--line`）。全屏只有一条 accent 线，符合 P2。

### 3.3 分栏与宽度

- 分栏线 1px `--line`，无阴影无间距（列之间不留 8px gutter——留缝会把两列读成两张卡片）。
- 列宽均分 `1fr`；用户可拖拽分栏线（比例持久化），最小 340。
- 列数上限由视口推导（见 §3.4）；超出上限时最旧/最右列自动关闭前提示（不静默丢 streaming 列）。

### 3.4 列数降级矩阵

| 视口宽 | 允许列数 | 侧栏 | 说明 |
|---|---|---|---|
| ≥1360 | 3 | 320 | 3×340 = 1020 + 320 = 1340，留余量 |
| 1180–1359 | 2 | 320 | 第 3 列降级为"后台列"（保留 streaming，可从 switcher 唤回） |
| 1024–1179 | 2 | 56 rail | 2×440 可读 |
| 769–1023 | 1 + 列切换器 | rail | 列切换器 = 顶部 32px 分段控件 `01 02 03`，各带状态点 |
| ≤768 | 1（移动） | 抽屉 | 见 §4 |

降级**不销毁**列：`--col-count` 只是视图数，后台列继续收事件（streaming 完成时列切换器上闪一次 accent 点）。恢复宽屏时按记录恢复。

### 3.5 列内滚动与"跟随"

- 每列一个滚动容器（`.column-log`），`overflow-y:auto; scrollbar-gutter:stable`。
- **跟随模式**：滚动到距底 ≤48px 视为跟随；新消息自动滚底。用户上滚即退出跟随，右下浮出 `↓ 回到底部`（32px quiet，距底 12px）。
- 切换列/重渲染**不得**重置滚动（记住 `scrollTop`）；打开会话默认滚到底（最后看的位置优先，若存过则恢复）。
- streaming 时每 120ms 合并一次滚动，避免抖动。

### 3.6 列级操作清单

| 操作 | 入口 | 行为 |
|---|---|---|
| 新建列 | 侧栏 `＋` 旁下拉：`新会话` / `新列` | 新列 = 空会话，模型继承当前列 |
| 聚焦列 | 列头 `⤢` | 其他列收为 40px 窄条（保留状态点），Esc 退出 |
| 关闭列 | 列头 `⋯` → 关闭 | streaming 中需确认（危险确认框） |
| 克隆会话 | 列头 `⋯` → 克隆 | 复制为第 N+1 列 |
| 打开 Changes | 列头 `⋯` → Changes / Header 的 Changes | 打开 Diff 面板（绑定该列） |
| 拖拽排序 | 拖列头 | 调整列顺序 |

## 4. 移动端（≤768px）

目标场景：Tailscale 远程查看进度、发一句话、看工具是否卡住。**不是完整替代桌面。**

> 目标视觉：`preview-mobile.png`（单列 + 固定输入）、`preview-mobile-drawer.png`（抽屉展开）。

### 4.1 结构

```
┌─────────────────────────────┐
│ ☰   B8 视觉重设计    Changes│  48  Header（sticky）
├─────────────────────────────┤
│                             │
│   会话流（唯一滚动区）      │  padding 16
│   左轨保留，序号 10px       │
│                             │
│                             │
├─────────────────────────────┤
│ ┌─────────────────────────┐ │  Composer（fixed bottom）
│ │ 继续讨论…            ↑  │ │  最小 56，随内容长高至 40dvh
│ │ 📎  v4.1 ▾  high ▾     │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘  + env(safe-area-inset-bottom)
```

- Header 48px：`☰`（44×44）+ 会话标题（13px 省略）+ `Changes` 计数。状态点并入标题左侧。
- Composer **固定在底部**（`position:sticky; bottom:0` 在列内 + `padding-bottom: max(12px, env(safe-area-inset-bottom))`），背景 `--canvas`，上边 1px `--line`，不用阴影。
- 输入框 `font-size:16px`（否则 iOS 聚焦自动放大），`Enter` 换行 → 移动上 `Enter` = 发送、换行靠换行键位说明（避免误发，改为 `Enter` 发送 + 长按提示）。
- 键盘弹起：用 `100dvh` + `visualViewport` 监听，把 Composer 顶到可视区底部；**不依赖** `position:fixed`（iOS 上有跳动）。

### 4.2 抽屉

- 宽 300px（`min(300px, 84vw)`），从左侧 240ms `--ease-std` 滑入；遮罩 `--scrim` 点击关闭，`Esc` 关闭。
- 抽屉内：顶部 `＋ 新会话`（44 高，primary ghost 全宽）+ 分组/会话行（56 高，44 命中）。
- 抽屉打开时背景内容 `overflow:hidden` 冻结滚动，但**不 blur**（blur 在这个系统里是装饰）。
- 选中会话后：抽屉关闭 + 内容切换 + 滚到底。

### 4.3 移动端组件降级

| 桌面 | 移动 |
|---|---|
| 3 列 | 1 列 + 顶部列切换器（下滑收起为 3 个点） |
| hover 出现行内操作 | 常显 / 长按出动作表（`从这条分支 / 复制 / 复制链接`） |
| 右侧面板 docked | 全屏 sheet（底部滑入，抓手关闭），树/文件/Diff 共用 |
| 工具行 hover 复制 | 整行可点开结果，展开后底部 actions |
| 模型分组下拉 | 底部动作表（Bottom Sheet，44 行高） |
| Toast 右下 | Composer 上方居中，宽减 32 |

### 4.4 触摸与安全区

- 所有可点目标 ≥44×44（含会话行、工具行、树行、图标按钮）。
- 行间距不做负 margin 补偿命中区（会串行误触）。
- 安全区：`padding: env(safe-area-inset-*)`；横屏 ≤768 宽时同样走移动布局（判宽不判朝向）。

## 5. 右侧面板

| 面板 | 宽 | 桌面形态 | 移动形态 |
|---|---|---|---|
| 树 | 340 | 停靠右（≥1280）/ 浮层（<1280） | 全屏 sheet，高 88dvh |
| 文件 | 420 | 同上 | 全屏 sheet |
| Diff | 420 | 同上 | 全屏 sheet（左右分栏改上下：旧上/新下） |
| 设置 | 480 | 模态（`--e2`） | 全屏 sheet |

- 同时只允许 1 个面板打开（避免三面板挤压列宽）。
- 面板打开时若可用列宽 < 340，面板自动转浮层（覆盖在会话上，右侧 12px 外边距）。
- 面板与列绑定：面板记录"我属于哪一列"，多列切换时面板内容随活动列切换（切换有 140ms 交叉淡入，不做滑动）。

## 6. 空态 / 首屏

首屏（无会话选中）不是"空白 + 提示语"，而是**最小可用面**：
- 中间：`选一个会话，或直接输入开始`（19px）+ 一行 `空会话不落盘：发出第一条消息后才出现在左侧`（13px `--ink-3`）。
- 下方 Composer 保持原位可输入（现状问题：空态时 Composer 仍在但视觉上与空白区脱节 → 新布局中用 1px 顶线把它锚定）。
- 侧栏保持完整（不是骨架屏）——单人产品的首屏应该是"我的现场"，不是营销插画。

## 7. 层级与 z-index 约定

| 层 | z | 内容 |
|---|---|---|
| 0 | — | 列/侧栏/面板 |
| 10 | 10 | sticky 列头、sticky Composer |
| 20 | 20 | 下拉、popover、`↓ 回到底部` |
| 30 | 30 | 停靠面板的浮层形态 |
| 40 | 40 | 抽屉 + 遮罩 |
| 50 | 50 | 模态 / 确认框 |
| 60 | 60 | Toast |

禁止用 `z-index: 9999`；新增层必须登记到本表。

## 8. 布局验收清单（实现阶段逐条打勾）

- [ ] `1440×900`：侧栏 320 + 单列（内容 860 居中，同类同宽）+ 树面板 340，无横向滚动
- [ ] `1440×900`：双列，两列独立滚动，切换列不重置滚动位置
- [ ] `1280×800`：3 列自动降为 2 列，第 3 列仍 streaming
- [ ] `1024×768`：侧栏 rail，2 列，面板改浮层
- [ ] `768×1024`：单列 + 列切换器，侧栏抽屉
- [ ] `390×844`：单列 + 固定 Composer，所有命中区 ≥44，抽屉可开合，键盘弹起不遮输入
- [ ] 任意宽度：页面本身不产生滚动条（只有列/面板内部滚动）
- [ ] `prefers-reduced-motion`：无动效残留
