# 有什么新东西（用户视角版本说明）

> **维护约定：每次小版本（`x.Y.0`）在这里新增一节。**
> 顺序：新的在上面。每节 3–6 条「你会感受到的变化」+ 最后一条「升级注意」；只写用户能感知的事，不写模块名、函数名、内部机制。
> 发布前必须与 `ARCHITECTURE.md`、`USER-GUIDE.md`、`RELEASE-NOTES.md`、`CHANGELOG.md` 一起同步（见 `docs/RUNBOOK.md` §3）。

**如何查看当前版本**：点顶栏 `⋯`，菜单底部有 `pi  <版本号>`（以及 `pid`）。或者看仓库 tag：`git tag --sort=-v:refname`（最新的在最上面）。

## v1.2.0 · 2026-11-25 · 大会话也能秒接

1. **十几 MB 的老会话，点开就接上**：以前接管要等引擎把「整条会话装进一行」吐回来，会话一大就撞上限、只剩干等超时；现在改由桥直接读会话文件，会话多大都不影响接管速度。打开、接管、断线重连、重启后恢复，全都受益。
2. **再也不会「提示已受理、却一直转圈」**：恢复进行中的那几秒，后台的空闲回收偶尔会把正在切换的引擎当成闲置进程收掉，页面就只能看到失败。现在这期间引擎被明确标记为「忙」，不会被回收，恢复能稳定跑到终点。
3. **接管后的内容与只读浏览一致**：两条路走同一个读盘解析器，不会再出现「浏览能看、接管后对不上」的错位。

**升级注意**：`git pull` 后重启即可，无需改配置、不迁移数据；关列后约 30s 内回来同会话仍会提示 409（这条门槛未变）。

## v1.1.0 · 2026-11-25 · 桌面化

1. **桌面图标 + 一键快捷方式**：跑一次 `scripts\setup-windows.ps1`，桌面就有 `pi-shell` 快捷方式（可随时 `-Remove` 移除，只动它自己的两个文件）。
2. **托盘模式，不再挂着一个黑窗口**：双击快捷方式启动后只有右下角一个图标，右键可打开页面 / 重启 / 停止；鼠标悬停能看到当前引擎数；图标跟随系统浅 / 深色主题。
3. **超大会话能接入了**：JSONL 单行上限从 8MiB 提到 32MiB，之前因「一行太长」接不上的会话恢复可用；极端情况可用 `PI_SHELL_MAX_LINE_BYTES` 再调。

**升级注意**：跑一次 `scripts\setup-windows.ps1` 才会得到新的托盘快捷方式；旧的启动窗口方式仍可用（`scripts\start-pi-shell.cmd`）。

## v1.0.0 · 2026-11-18 · 首个公开发布

1. **一个页面并行开 1–3 个会话**：每列独立引擎与输入框，同时生成互不打断；切走或关标签不会杀掉正在跑的回合，回来接着看，没写完的部分自动补上。
2. **手机也能连**：装了 Tailscale 时，同一端口自动多开一个手机地址（`http://100.x.y.z:7788`），桌面地址照旧；不开公网。
3. **断线 / 重启不丢上下文**：页面断线自动重连；重启整个 pi-shell 后，每列会自动接回上次那条会话（含模型与思考级别）；万一接不回来，会明确提示并拦住发送，不会悄悄把消息发进空会话。
4. **MCP 按需开**：默认不加载任何 MCP server（省内存、切换快）；要用时在 `⋯` → MCP 里按列勾选，或写规则文件按项目自动带。
5. **看得清 AI 干了什么**：工具行带耗时、嵌套折叠；顶栏 Changes 直接看这一轮改了哪些文件和行内 diff。

**升级注意**：首个公开发布，无旧版本可升级；从 clone 到能用的完整路径见 `README.md`「安装」。
