# 有什么新东西（用户视角版本说明）

> **维护约定：每次小版本（`x.Y.0`）在这里新增一节。**
> 顺序：新的在上面。每节 3–6 条「你会感受到的变化」+ 最后一条「升级注意」；只写用户能感知的事，不写模块名、函数名、内部机制。
> 发布前必须与 `ARCHITECTURE.md`、`USER-GUIDE.md`、`RELEASE-NOTES.md`、`CHANGELOG.md` 一起同步（见 `docs/RUNBOOK.md` §3）。

**如何查看当前版本**：点顶栏 `⋯`，菜单底部有 `pi  <版本号>`（以及 `pid`）。或者看仓库 tag：`git tag --sort=-v:refname`（最新的在最上面）。

## v1.0.0 · 2026-11-18 · 首个公开发布

1. **一个页面并行开 1–3 个会话**：每列独立引擎与输入框，同时生成互不打断；切走或关标签不会杀掉正在跑的回合，回来接着看，没写完的部分自动补上。
2. **手机也能连**：装了 Tailscale 时，同一端口自动多开一个手机地址（`http://100.x.y.z:7788`），桌面地址照旧；不开公网。
3. **断线 / 重启不丢上下文**：页面断线自动重连；重启整个 pi-shell 后，每列会自动接回上次那条会话（含模型与思考级别）；万一接不回来，会明确提示并拦住发送，不会悄悄把消息发进空会话。
4. **MCP 按需开**：默认不加载任何 MCP server（省内存、切换快）；要用时在 `⋯` → MCP 里按列勾选，或写规则文件按项目自动带。
5. **看得清 AI 干了什么**：工具行带耗时、嵌套折叠；顶栏 Changes 直接看这一轮改了哪些文件和行内 diff。

**升级注意**：首个公开发布，无旧版本可升级；从 clone 到能用的完整路径见 `README.md`「安装」。
