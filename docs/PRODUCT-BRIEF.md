# PRODUCT-BRIEF · 这是什么、现在能做什么、哪里不能信

> 写这份文件的人：项目 Owner（价值负责人）。写它的目的不是"介绍功能"，是让读者在点开它之前就知道**哪些是真能用、哪些是坏的、哪些我没验**。
> 全部结论来自 2026-11-06 的实机审计（`scripts/evidence/product-audit.mjs` + 6 次专项探针），**没有一条来自开发方的自测脚本**。
> 口径：只认「界面 + 真实鼠标/键盘」；只测 API 不算交付。

---

## 1. 它是什么（一句话）

**给你本机官方 pi 1.5.0 加的一层浏览器外壳**：读同一份 `~/.pi/agent`（配置/扩展/技能/会话），不新装引擎，不复制数据；卸载 = 删目录 + 删一个 `.lnk`。

它不改变 pi 的能力边界——**它改变的是"看"和"选"的成本**。

---

## 2. 客观上讲，它给你四件事（都会在界面上发生）

| # | 它实际做的事 | 为什么可能对你有用 |
|---|---|---|
| 1 | 把 116 个会话、6 个项目组、标题/时间/末条摘要摆在一屏，支持子串过滤 | 找"昨天那轮结论"不用再翻目录、记 `resume` |
| 2 | 打开一个 306 条的长会话：**204ms 出内容**、Markdown/表格/代码块、thinking 与 51 个工具调用默认折叠、点一下展开原始内容 | 长对话与工具输出在终端里最难读，这里能一眼扫 |
| 3 | 命令面板 Ctrl+K：扩展命令 / 提示词模板 / 技能三类都在，输入即过滤（数量取决于你的 pi 配置） | 你不用记住命令的拼写 |
| 4 | 会话树（306 节点，含 fork 按钮）、工作区文件浏览（222 项，越界 403）、成本/上下文（token/美元/ctx） | 少开两个窗口；知道这轮花了多少 |

**它不给你**：IDE、多用户、远程/手机、审批层、开机自启、全文检索（这些从立项起就是"不做"）。

## 5. 我没验的（不要当成"能用"）

- 图片粘贴 / 文件注入（`Ctrl+U`，≤200KB）
- 扩展对话框桥（select/confirm/input/editor）—— 你本机 4 个扩展都不用这四类，属预留
- 工作区切换（历史证据有，含 ≈3s 重启）
- fork / clone 的真实效果（只看了入口，没敢动你的会话文件）
- 断线重连（历史证据有，我未复跑）
- 主题 / 密度（只验了字号）

---

## 6. 现在这份东西的"客观价值"

**下限**：一个只读、比终端舒服的**会话浏览器** + 一个能发消息的输入框（要点按钮）。
**上限**：把"找会话、读长对话、跑自定义命令"这三件事从终端里拿出来，让你不用记路径和命令名。

**它现在的真实定位**：**可用，但还没到"顺手"**。D-1 修掉之前，它比终端慢；D-1/D-2/D-3 修掉之后，它才谈得上"日常能待"。

---

## 7. 按现状试用的操作要点（如果你现在就要试）

1. 双击桌面 `pi-shell`，等 1–2s 浏览器自己开。
2. 左侧点一条会话 → 先能读（看到"接管中…"），约 1 秒后发送按钮变亮。
3. **发消息按 Ctrl+Enter**（Enter / Shift+Enter 都是换行，⌘+Enter 同效）；点了「发送」同样可以。
4. 看 diff 请用终端（D-4，界面没有入口）。
5. 桥崩了/被杀了，它会在 1 秒内自己回来；如果 5 分钟内崩 4 次，脚本会停下并提示，不会再无限重启（`logs/launcher.log` 有记录）。
6. 别扭的地方记一句话给我——**别扭就是需求**，比任何功能清单都值钱。
